Section 01

Core Concepts

Click each card to reveal the full concept. Remove any one of the five pillars and autonomy collapses.

🎯

Goal Orientation

The agent always has an objective it's working toward.

Tap to expand ↓

A true agent has an objective. Without a goal, a system is reactive — just responding to prompts with no through-line. Agents pursue outcomes across multiple steps, choosing actions based on what will best advance toward that goal.
🤔

Decision-Making

Agents evaluate options and choose a path.

Tap to expand ↓

Agents can evaluate options and choose a path. This isn't just "pick from a list" — it's reasoning under uncertainty about what action to take next, weighing trade-offs, and committing to a course of action.
⚡

Action Execution

Tools give agents the ability to act on the world.

Tap to expand ↓

Words without hands are just advice. Tools give agents real-world impact: query databases, run code, send emails, trigger workflows, modify systems. Without tools, even the smartest LLM is just generating text.
🔁

Iteration

Agents loop — try, observe, adjust, repeat.

Tap to expand ↓

Agents don't stop after one response. They loop: try something, observe the result, and try again. Multi-step tasks require the ability to course-correct. This iterative loop is fundamentally different from a one-shot chatbot exchange.
🧬

Adaptation

Agents modify strategy based on feedback.

Tap to expand ↓

The agent modifies its strategy based on observed outcomes — not just retrying the same failing approach, but genuinely adjusting. This feedback-driven behavior separates autonomous systems from rigid automation.
🧠

Memory & State

Without memory there is no continuity.

Tap to expand ↓

Agents need three types: short-term (current context, recent actions), long-term (persistent facts, learned preferences), and task tracking (progress, pending actions). Remove any one and complex workflows collapse.
The Key Distinction

Assistant vs. Agent

This is the most important distinction you need to be able to articulate fluently.

💬  AI Assistant
—Stateless interaction
—Responds to a single prompt
—Text in → text out only
—No persistent memory
—Waits for your next message
🤖  AI Agent
→Persistent goal pursuit
→Executes multi-step plans
→Tool-equipped — acts on the world
→Maintains memory across steps
→Loops until the goal is met

INPUT — A task or trigger starts the loop. This could be a user message, a scheduled event, an API call, or a detected system condition. The agent now has something concrete to work toward.
🩺  Example: Healthcare Scheduling Agent
INPUT
Book a follow-up appointment for patient #3842 within 2 weeks.
INTERPRET
Patient needs a cardiologist within 14 days, preferably same provider.
PLAN
Check provider availability → filter by specialty → match patient insurance.
ACT
Query scheduling API. Search 3 providers. Identify open slot on Tuesday.
OBSERVE
Slot found, but conflicts with patient's stated preference (no Fridays) on file.
ADJUST
Search next non-Friday slot → book → send confirmation to patient and provider.

Section 05

Power, Limits & Responsibility

Autonomy increases both capability and attack surface. Every agent designer must understand these before deploying.

Current Limitations
🧭

Long-Horizon Planning

Agents lose coherence over extended multi-step tasks. They work well for 3–5 steps but degrade significantly beyond that. Design for shorter sub-tasks with human checkpoints.

HIGH
💾

Stable Memory

Context windows are limited. Persistent memory via vector DBs and RAG helps, but is imperfect. Agents can "forget" critical context mid-workflow on complex tasks.

MED
🔄

Error Recovery

When something goes wrong, agents often compound mistakes by retrying the same failing strategy. They need explicit error-handling logic — not just retry loops.

HIGH
Security Threats
💉

Prompt Injection

Malicious instructions embedded in data the agent reads — emails, documents, API responses — can hijack the agent's behavior entirely, turning it against its intended purpose.

CRITICAL
📤

Data Exfiltration

An agent with broad data access can inadvertently expose sensitive information through API calls, log entries, or tool outputs. Apply the principle of least privilege — always.

CRITICAL
🔧

Tool Misuse

Agents can use legitimate tools in unintended ways — deleting production data while "cleaning up," or sending messages to the wrong recipients at scale.

HIGH
